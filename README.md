# 95cbsv 映盒 / drpy2 本机 JS 适配

本仓库提供一个 JSON 订阅入口和一个 drpy2 JavaScript 规则文件。

## 映盒导入

订阅地址：

`https://raw.githubusercontent.com/BigJakeJay/95cbsv/main/95cbsv.json`

## 文件

- `95cbsv.json`：单站点 JSON 配置。
- `95cbsv.js`：分类、推荐、搜索、详情及播放线路规则。

## 运行要求与限制

- 配置使用 `type: 3` 的 drpy2 JS 站点规则。
- 不使用 XBPQ、JAR 或需要服务端执行的插件。
- 客户端必须支持加载 JSON 中的远程 `api` 和 `ext`。
- 规则依赖目标站点当前页面结构及其播放器脚本；站点改版可能导致解析失效。
- 当前版本已整理列表卡片标题解码和 H.264 / AV1 / MP4 地址拼接逻辑，但尚未在映盒客户端完成端到端验证。尤其需要实测分类翻页、详情字段、播放解密与实际解码。

## 播放线路

详情页播放器参数用于动态构造线路，不将单个影片地址写死：
- H.264 普通线路
- H.264 极速线路
- AV1
- MP4 下载地址

如果站点调整播放器参数名、路径或域名，需要同步更新 `95cbsv.js`。
